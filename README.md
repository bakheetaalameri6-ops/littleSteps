# LittleSteps

School management for staff, students, guardians, attendance, gate control and auditing.

C# / ASP.NET Core .NET 8 API, PostgreSQL 16, database-first EF Core, and plain HTML with Bootstrap 5 and DataTables.

The original documents and prototype remain locally in ignored `docs/` and `handoff/` folders. PostgreSQL replaces SQL Server at the project owner's request; Npgsql replaces the SQL Server EF provider.

Implementation follows the five modules and domain diagrams. Completed modules are committed separately.
